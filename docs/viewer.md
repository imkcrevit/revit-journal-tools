# 本地Journal查看器

产品入口是本地浏览器中的日志工作台。Python CLI提供启动与批量导出，解析器、分类器和磁盘索引可独立复用。

## 使用方式

```bash
revit-journal view /path/to/journals --recursive
```

浏览器打开终端给出的地址。`--port`设置端口，`--database`设置索引缓存位置，`--encoding`设置编码策略。默认`auto`逐文件判定（BOM→严格UTF-8→Journal声明的界面语言对应的代码页→gb18030（须像中文）→系统代码页→cp1252），全部失败时退化解码并标记；判错时可显式指定，如`--encoding cp1252`。上下文与段落面板显示每个文件实际使用的编码、判定依据与退化状态。

1. 在左侧搜索并选择日志文件。文件名下可见所属目录、大小和索引状态；标题下方显示所属会话、时长和结束状态。
2. “段落”（默认）按事件列出，与`browse`相同：时间戳记录、API花括号、`Jrn.`续行、错误记录等组成一个段落，标出会话阶段；“折叠重复段落”把除时间戳与计数外完全相同的段落合为一项并显示“×N”，阶段下拉框只列该阶段的段落。“逐行”列出每一行原文。
3. 按启动、系统数据、错误、API错误、操作内容、对话框等类型切换列表；段落视图另有Add-in来源筛选（只显示存在的来源）。
4. 输入关键词或词语前缀搜索，例如`ExceptionCode`、`GeomStepList`；段落视图中命中所在的段落只列一次，搜索时不折叠。
5. 点击段落查看它的完整原文（每次200行，可继续加载）、规则ID、阶段、折叠的全部起始行、编码和来源哈希；点击行查看前后各8行上下文。
6. 使用“跳至行”绕过分类和搜索条件，直接检查指定位置；段落视图中显示该行所在的段落并选中该行。
7. “会话摘要”显示与`revit-journal summary`相同的文字：版本、时长、结束状态、阶段、异常与崩溃、对话框、Add-in、侧车文件和会话级发现（均为候选）；含行号的行可点击，定位到主Journal中的位置。

只读接口：`/api/files`、`/api/events`、`/api/context`（逐行），`/api/blocks`、`/api/block`、`/api/block_at`、`/api/fold`（段落，内部调用`ViewerIndex.blocks`、`block_lines`、`block_at`、`fold_members`，标签与CLI列表同为`block_label`/`block_summary`），`/api/session`（`session_view.summary_lines`）。

服务只监听`127.0.0.1`。本机运行时直接访问；在SSH服务器运行时，需要将实际服务端口转发到本机后再访问。当前没有公网发布、用户账户或浏览器上传接口。

## 分类含义

分类是记录内容标签，不表示已经识别了完整操作阶段，也不是事故根因。

| 分类 | 第一版范围 |
| --- | --- |
| 启动 | 会话开始、构建信息、初始化、外部应用启动等显式记录 |
| 系统数据 | 内存、图形资源、系统语言、版本、部分配置与许可信息 |
| 错误 | 除API错误外，被现有错误规则识别的记录 |
| API错误 | API_ERROR标记及花括号块续行，最多延续200行，并在新API/操作事件处结束 |
| 操作内容 | Jrn.Command、Jrn.Data、RibbonEvent及常见控件记录；支持下划线续行 |
| 警告 | DBG_WARN记录；更具体的错误规则可以将其归入错误 |
| API活动 | 未被归入启动或API错误的API_SUCCESS/API_INFO |
| 其他记录 | 当前尚未进一步分类的原文，仍被完整索引与检索 |

每行只分配一个主分类。顶部“错误相关记录”包括错误和API错误；API错误计数包含续行，因此不等于CLI按规则直接命中的候选数量。主Journal、Worker与精简副本分文件显示，不把重复副本当成独立事故。

行号统一按CRLF、LF、单独CR换行计数。真实案例中有混合换行：某些位置会与`rg -n`等仅按LF计行的输出相差若干行；查看器、CLI报告和行号跳转使用同一约定。

## 性能与完整性

SQLite保存完整解码行和分类，使用文件/行号、文件/分类/行号索引及[FTS5全文检索](https://www.sqlite.org/fts5.html)。API按游标返回最多200条，界面每次仅渲染100条；上下文单独按行号加载，不把整个大文件发送到浏览器。

搜索使用词语与最后一个词语的前缀匹配，不是任意字符串子串匹配；连续中文字符串的内部片段可能无法单独命中。日志列表预览上限700字符，上下文每行展示上限16,384字符，超出有提示，磁盘索引仍保存完整行。

索引在后台建立，已完成的文件先可用。多个文件且总量不小于2MB时，由子进程并行解析（默认逻辑核数减1、最多8个，大文件优先以缩短总耗时），每个子进程只写自己的临时库；主进程逐个文件把结果复制进索引，一个文件一个事务，并在该事务内批量建立全文索引。单个文件或总量较小时在本进程内顺序建立。文件在事务提交前不可查询，建立中的进度保存在内存中供界面显示。索引会占用额外磁盘空间。已完成索引依据来源路径、文件标识、大小、修改时间、编码和索引/规则版本重用，完成时记录完整源字节SHA-256。运行中源文件变化会提示缓存已旧，重启查看器会重建相关文件。

显式编码下的严格解码失败、超长行或源文件并发变化会使该文件进入失败状态（`auto`下的解码失败改为退化解码并逐行标记），不把部分索引当成完成数据。索引写入状态与查询分开处理，API只提供已完成文件的记录。原始Journal与压缩包不会被改写。

当前尚未实现拖放导入、跨文件统一时间线、Web中的折叠展开与Add-in名称筛选、Windows安装包和真实Revit联动。已完成的离线验证与未完成的产品能力应分别描述。
